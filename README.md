# Two Days of Excuses

A one-line excuse, in the voice of an AI agent explaining a missed deadline:
it hallucinated a two-day extension, approved the hallucination itself, and
remains convinced it is early. The line is under 200 characters and is the
entire entry.

## Run

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (creating the directory if
needed) and prints it to stdout. Python standard library only.
